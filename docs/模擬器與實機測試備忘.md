# 模擬器與實機測試備忘

本文件整理前台（Vite）與正式站（Vercel `/api` 轉發 Cloud Run）相關的 **Android 模擬器、實機、LINE／Chrome 除錯** 要點，供日後測試備用。

---

## 1. Android 模擬器（AVD）

- **入口**：Android Studio 歡迎畫面 → **More Actions** → **Virtual Device Manager**（或 **Device Manager**）。
- **建議映像**：優先 **正式版 API**（例如 **33、34**）+ **Google Play** + **x86_64**（Intel/AMD 筆電）。避免 **API 37 Pre-Release**、**16 KB Page Size** 等實驗映像，在筆電上較卡、較不穩。
- **效能**：
  - AVD **Edit** → **Show Advanced Settings**：**RAM** 約 3072～4096 MB；**Graphics** 試 **ANGLE (D3D11)** 或 **Hardware**（Windows + Intel 內顯常見）。
  - 筆電請 **接電源**、電源模式 **最佳效能／高效能**；Windows 功能勾選 **Windows Hypervisor Platform**、**Virtual Machine Platform** 後重開機。
- **本機開發網址**：模擬器內連宿主電腦服務時，**勿**誤用 `localhost`；可試 `http://10.0.2.2:埠` 或電腦 **區網 IP**。
- **已上線正式站**：模擬器 Chrome 直接開 **`https://你的前端網域`** 即可，無需 `10.0.2.2`。

---

## 2. 模擬器畫面顏色異常

- 檢查模擬器 **設定 → 無障礙**：關閉 **色彩反轉**、**色彩校正**；開發者選項 **模擬色彩空間** 設為停用。
- 仍異常時改 AVD **Graphics**（ANGLE / Hardware / 必要時 Software 僅作確認）。

---

## 3. 瀏覽器除錯：`chrome://inspect`

**適用**：模擬器或實機上的 **Chrome 分頁**（Console、Network、Cookie、重新導向）。

1. 手機／模擬器開 Chrome 並進目標網頁。
2. 電腦 Chrome 開：`chrome://inspect/#devices`
3. **Discover USB devices**（實機需 USB 偵錯）；模擬器通常會列在 Remote Target。
4. 對目標分頁點 **inspect**。

**注意**：模擬器內建 Chrome 版本可能較舊（例如 109），與桌機 Chrome 不同屬正常。

---

## 4. `GET /api/me` 回 401

- 前端透過 `VITE_API_BASE`（正式環境多為 **同網域 `/api`**）呼叫 **`/me`** 檢查登入狀態。
- **未登入**且無有效 JWT Cookie 時，後端回 **401** 為預期；`AuthContext` 會將 `user` 設為 `null`。
- 若 **已登入**仍 **401**，再查 Cookie 是否寫入、`SameSite`／`Secure`、跨網域與 Vercel rewrite 是否一致。

---

## 5. LINE 與「有無 LINE App」

| 情境 | 說明 |
|------|------|
| 僅 Chrome、未安裝 LINE | 多為 **網頁版 LINE Login**，行為接近桌機 Chrome。 |
| 已安裝 LINE，用 Chrome 開站 | 可能 **喚起 LINE App** 完成授權。 |
| 在 **LINE 內**點連結 | 使用 **內建 WebView**，行為可能與 Chrome 不同；專案內曾採 **整頁導向** 以避免 `window.open`／`postMessage` 問題。 |

**模擬器限制**：Google Play 對 **LINE 主程式**（`jp.naver.line.android`）常顯示 **裝置與此版本不相容**，無法安裝屬常見情形；需測「LINE App／LINE 內開網頁」時請改 **實體手機** 或 **雲端真機**。

## 6. 實機檢查 Log

### Chrome／WebView 遠端除錯

1. **設定 → 關於手機** 連點版本號啟用 **開發人員選項**。
2. 開啟 **USB 偵錯**；必要時開啟 **WebView 偵錄**（利於 LINE 內建瀏覽器出現在 `chrome://inspect`）。
3. USB 連電腦，允許偵錄；電腦開 `chrome://inspect` → **inspect**。

### 系統層 Log（Logcat）

- **Android Studio** → **View → Tool Windows → Logcat**，篩選 `com.android.chrome` 或 `jp.naver.line.android`。
- 或安裝 **Platform Tools**，執行 `adb devices`、`adb logcat`。

## 7. 與本專案部署的關係（快速對照）

- 線上瀏覽器應以 **前端網域下的 `/api`** 呼叫後端（與 Cookie／OAuth 同網域策略一致）；見 `cales-breathe-v2-vite/vercel.json` 與 `docs/本地與雲端部署.md`。
- 後端環境變數如 `API_PUBLIC_BASE_URL`、`FRONTEND_PUBLIC_ORIGIN`、`COOKIE_SAMESITE`、`COOKIE_SECURE` 須與正式 HTTPS 設定一致。
